# Examples

Run from repo root: `python examples/<script>.py`. Requires venv (see main [README](../README.md)).

- **api_usage.py** – Programmatic API: get representation, create genome, render, develop, mutate, crossover, save.
- **evolution_batch.py** – Batch evolution with a proxy fitness; uses default representation from config. Saves best individual.
- **time_signal_showcase.py** – Plots modified time vs raw time for dual-CPPN (time network as “heartbeat”). Requires matplotlib.
